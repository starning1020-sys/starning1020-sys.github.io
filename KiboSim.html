Int-Ball2 在 Kibo 艙裡怎麼跑一趟任務

第 7 屆 Kibo-RPC 預賽的任務，用 3D 拆開來看：無人機從 Dock 出發，依序飛到每個 CheckPoint、對準 AR marker、等穩定後請伺服器判定，最後回到終點回報。按「執行任務」看我們的程式邏輯實際走一遍。

IB2 MAIN CAMERA

拖曳旋轉、滾輪縮放；面向你的那面牆會自動剖開。AR marker 座標取自官方規則書，為了看得見而放大（實際邊長 2 cm）。CheckPoint 位置、判定等級與艙內機櫃配置為示意。

三個要記住的觀念

程式是蒙眼的駕駛

程式看不到這個 3D 畫面，只能透過 API 拿到位置、姿態的數字和相機影像，再下「飛到某座標」的指令。裁判則是用 3D 世界裡的真實位置判定。

判定有三個條件

位置要在球內（Lv3 半徑僅 10 cm）、AR marker 要在相機畫面中央、繞視線的旋轉角要對，並維持 1 秒。三項取最低等級，任一項不合格就是 0 分。

時間是最重要的資源

任務限時 300 秒，超時就沒有完成分和時間倍率。程式每次出發前都會先算「去下一點再回終點」來不來得及，不夠就直接收尾。

程式的流程

  1. 任務開始收到 start 訊號後呼叫 mission_start，記下起始時間。
  2. 讀取 CheckPointget_checkpoints 回傳每個點的位置、目標姿態與判定範圍。
  3. 規劃路線最近鄰法排順序，再用 2-opt 改善，終點固定放最後。
  4. 時間檢查後飛行確認時間夠，才用 /ctl/command 飛過去。
  5. 穩定、預測、判定速度夠低並維持 0.5 秒，自己先算等級，再送 checkpoint_passed。
  6. 回終點回報飛到終點判定，然後一定送出 mission_finished。
